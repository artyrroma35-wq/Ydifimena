# Тише — личная орбита

Небольшое автономное веб-приложение для спокойного планирования дня и фокус-сессий. Сделано на чистых HTML, CSS и JavaScript — без сборки, сервера приложений, аккаунта и сторонних библиотек.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте `http://localhost:8000`.

## Что внутри

- интерактивная карта намерений: добавление, выбор, завершение и удаление точек;
- таймер фокуса на 15, 25, 45 или 60 минут с паузой и сохранением после перезагрузки;
- дневная статистика и сохранение плана в `localStorage`;
- мягкий синтезированный шум без аудиофайлов и запросов к сети;
- три цветовых настроения и короткая дыхательная пауза;
- клавиши `N` — новая точка, `Space` — старт/пауза, `R` — сброс таймера, `Esc` — закрыть паузу.

Все действия локальные: план остаётся в текущем браузере.
